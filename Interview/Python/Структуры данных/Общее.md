## 📋 Сравнительная таблица свойств

| Структура     | Изменяемая | Упорядоченная | Индексируемая | Дубликаты         | Хешируемая |
| ------------- | ---------- | ------------- | ------------- | ----------------- | ---------- |
| **list**      | ✅ Да       | ✅ Да          | ✅ Да          | ✅ Да              | ❌ Нет      |
| **tuple**     | ❌ Нет      | ✅ Да          | ✅ Да          | ✅ Да              | ✅ Да*      |
| **dict**      | ✅ Да       | ✅ Да (с 3.7)  | ✅ По ключу    | ❌ Ключи уникальны | ❌ Нет      |
| **set**       | ✅ Да       | ❌ Нет         | ❌ Нет         | ❌ Уникальные      | ❌ Нет      |
| **frozenset** | ❌ Нет      | ❌ Нет         | ❌ Нет         | ❌ Уникальные      | ✅ Да       |
| **str**       | ❌ Нет      | ✅ Да          | ✅ Да          | ✅ Да              | ❌ Нет      |

*Кортеж хешируем, только если все его элементы хешируемы

## ⏱️ Сложность операций
### Список (list)

| Операция                        | Средний случай | Худший случай | Пояснение                  |
| ------------------------------- | -------------- | ------------- | -------------------------- |
| **Доступ по индексу**           | O(1)           | O(1)          | Прямая адресация           |
| **Поиск элемента**              | O(n)           | O(n)          | Линейный поиск             |
| **Добавление в конец (append)** | O(1)           | O(n)          | Амортизированная константа |
| **Вставка в начало/середину**   | O(n)           | O(n)          | Сдвиг элементов            |
| **Удаление с конца (pop)**      | O(1)           | O(1)          |                            |
| **Удаление из середины**        | O(n)           | O(n)          | Сдвиг элементов            |
| **Срез [i:j]**                  | O(k)           | O(k)          | k = j-i элементов          |
| **Разворот (reverse)**          | O(n)           | O(n)          |                            |
| **Сортировка (sort)**           | O(n log n)     | O(n log n)    | Timsort                    |
| **Умножение (list * n)**        | O(n * k)       | O(n * k)      |                            |
### Кортеж (tuple)

| Операция               | Сложность | Пояснение            |
| ---------------------- | --------- | -------------------- |
| **Доступ по индексу**  | O(1)      | Как в списке         |
| **Поиск элемента**     | O(n)      | Линейный поиск       |
| **Длина (len)**        | O(1)      | Хранится в заголовке |
| **Создание из списка** | O(n)      | Копирование          |
| **Распаковка**         | O(n)      | Зависит от размера   |
### Словарь (dict)

| Операция            | Средний случай | Худший случай | Пояснение                         |
| ------------------- | -------------- | ------------- | --------------------------------- |
| **Доступ по ключу** | O(1)           | O(n)          | Хеш-таблица                       |
| **Вставка**         | O(1)           | O(n)          | Может потребовать перехеширования |
| **Удаление**        | O(1)           | O(n)          |                                   |
| **Поиск ключа**     | O(1)           | O(n)          |                                   |
| **Поиск значения**  | O(n)           | O(n)          | Нет индекса                       |
| **Итерация**        | O(n)           | O(n)          |                                   |
### Множество (set / frozenset)

| Операция                | Средний случай           | Худший случай        | Пояснение |
| ----------------------- | ------------------------ | -------------------- | --------- |
| **Добавление**          | O(1)                     | O(n)                 |           |
| **Удаление**            | O(1)                     | O(n)                 |           |
| **Поиск (in)**          | O(1)                     | O(n)                 |           |
| **Объединение (union)** | O(len(s1) + len(s2))     | O(len(s1) + len(s2)) |           |
| **Пересечение**         | O(min(len(s1), len(s2))) | O(len(s1) * len(s2)) |           |
| **Разность**            | O(len(s1))               | O(len(s1) * len(s2)) |           |
## 💾 Память и производительность

### Сравнение памяти (приблизительно)

|Структура|10 элементов|1000 элементов|1M элементов|
|---|---|---|---|
|**list**|~120 байт|~8 КБ|~8 МБ|
|**tuple**|~80 байт|~8 КБ|~8 МБ|
|**dict**|~240 байт|~40 КБ|~40 МБ|
|**set**|~240 байт|~40 КБ|~40 МБ|

### Быстродействие операций (Big O)

```text
Операция       list    tuple    dict    set
─────────────────────────────────────────────
Доступ         O(1)    O(1)     O(1)*   ❌
Поиск          O(n)    O(n)     O(1)*   O(1)*
Вставка        O(1)**  ❌       O(1)*   O(1)*
Удаление       O(n)    ❌       O(1)*   O(1)*
Длина          O(1)    O(1)     O(1)    O(1)
* - средний случай, в худшем O(n)
** - амортизированная сложность
```
